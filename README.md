A synthetic bilingual (Tagalog-English) instruction-tuning dataset 
developed for the Kasangga chatbot research project.

## Dataset Details
- Total pairs: 2,500 instruction-response pairs
- Format: JSON array
- Language: Taglish (Tagalog-English code-switched)
- Domain: Emotional support and companionship
- Fields: instruction, response, emotion_label, language_type

- ## Usage
This dataset was used to fine-tune Meta Llama 3-8B-Instruct 
using PEFT with LoRA for Taglish emotional support response generation.


## Citation
Castillo, G. J. S. (2026). Kasangga: A Tagalog-English NLP Chatbot 
for Providing Emotionally Supportive and Non-Judgmental Conversation. 
University of Southern Mindanao.
